# GenFaD

## Setup
If you are not on a Linux system, setup a WSL, VM, or dual-boot (or any other method you prefer).

1. Create a [Kaggle](https://www.kaggle.com/) account
2. Generate an API key: Settings > API > Create New Token (will automatically a `kaggle.json` file)
3. Move the `kaggle.json` file to `~/.config/kaggle`
4. Install your preferred python environment manager (ie. miniconda, pyenv, virtualenv, etc)
5. Create a python environment
6. Install kaggle API: `pip install kaggle`
